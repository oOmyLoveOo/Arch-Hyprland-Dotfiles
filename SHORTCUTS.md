# Keyboard shortcuts

Generated from the live Hyprland binds by `~/.local/bin/keybinds.sh md`.
Edit `.config/hypr/conf/keybinds.lua`, then re-run the script.
Press `Super + H` for a searchable version of this list.

## Apps

| Shortcut | Action |
| --- | --- |
| `Super + H` | Shortcut cheat sheet (this list) |
| `Super + T` | Terminal (kitty) |
| `Super + E` | File manager (thunar) |
| `Super + A` | App launcher |
| `Super + L` | Lock screen |
| `Super + Shift + S` | Screenshot a region (copy + edit) |
| `Super + Shift + O` | OBS on the NVIDIA GPU |
| `Super + M` | Power menu |
| `Super + V` | Clipboard history |
| `Super + N` | Toggle night mode |
| `Super + .` | Emoji picker |
